# Salone App

Benvenuto nel progetto Salone App, il gestionale per salone di parrucchiere.

## Architettura

- **Frontend**: React + Vite (sostituisce Next.js in questo ambiente di sviluppo)
- **Backend**: Express.js (Node.js) + TypeScript
- **Database**: Supabase (PostgreSQL)
